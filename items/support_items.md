# Phantom Doctrine -- Support Items

**status:** research-integrated
**last_reconciled:** 2026-08-18

Off-map support requires **Tactical Recon** on the mission location first (opens N/E/S/W support slots). Support costs **Command Points**, which regenerate slowly; Workshop upgrades add more points.

## Support power types (unlock progressively)

| Type | Unlock | Effect |
|---|---|---|
| **Spotter (Watcher)** | initial; buy extra via Vendor on the deploy screen | Reveals enemies in line-of-sight + reduces their dodge (marks them undodgeable for 1 turn) |
| **Sniper support** | Workshop craft from a blueprint found via trade contacts/Analytics | Silenced hits deal <100 damage; loud hits deal >100 damage |
| **Grenade launcher** (frag / gas / smoke) | later Workshop blueprint | Area-effect support strike |
| **Cleaner** | later Workshop blueprint | Reduces mission Heat |

**Related achievements:** *Tactical Support* = own one of each type in a playthrough; *Combined Arms* = use 4 support powers in one turn.
